# Авто-генерация фильтров поиска (NLP-классификатор запросов)

Система извлечения структурированных сущностей из свободных текстовых запросов для поиска объявлений о работе. 
Решена задача от компании «Фарпост» в качестве дипломного проекта курса «Аналитик данных: продвинутый уровень» ДВФУ.
Пример: `«работа поваром посменно без опыта»` → `{role: повар, schedule: посменно, experience: без опыта}`.

### Ключевые возможности
- Автоматический разбор пользовательских запросов на структурированные фильтры
- Предобработка текста: лемматизация, удаление стоп-слов, нормализация
- Сравнение нескольких классификаторов, выбор оптимального по метрикам
- Полный ML-пайплайн, упакованный в Docker-контейнер

### Стек технологий
- ML / NLP: scikit-learn, pandas, pymorphy3
- Векторизация: Bag of Words, TF-IDF, One-Hot Encoding
- Модели: Logistic Regression, Random Forest, SVC и другие
- Инфраструктура: Docker

## Как это работает
Текстовый запрос проходит пайплайн предобработки (токенизация → лемматизация → векторизация). 
Обученные классификаторы предсказывают значения для каждого целевого фильтра. 
Выбор финальной модели основан на кросс-валидации и метрике `accuracy`. 
Инференс упакован в Docker для воспроизводимого запуска на любом хосте.

### Запуск
```bash
cd query_classifier
docker-compose up
```
После запуска по адресу `localhost:8000` доступен веб-интерфейс
